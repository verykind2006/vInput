## 二、⓪ 长语音：从丢三成到一字不丢

真机日志（session 21，遥控器固件上限的满格录音）：

```
22:12:46.783  按下
22:13:46.798  松开        ← 60.0 秒，5 次 MIC_EXTEND
22:13:52.553  注入成功 文本(231字): …而不是真的深度。
```

**60 秒、231 字、句子完整收尾。** 语速 3.85 字/秒，落在用户基准集实测的
3.1–4.6 区间内。

对照修复前（session 103）：31.4 秒只出 81 字、断在半句上，丢 20–35%。

成因与六变体对照见 `docs/Roadmap.md` 的 M6 ⓪ 一节。一句话：**VAD 分块把
连续语音切在句子中间，被切中的那块整块被判死**，而
`decodeWithFallback` 只返回最后一次退火结果、不保留最好的一次。

**决策为什么落在「关分块」**：四个候选都能把 dense-31 从失败打到 0/12，
「是否修好」这一列**完全不具区分度**。区分它们的是静音幻觉——每个动
`firstTokenLogProbThreshold` 的变体都把它从 0/24 拉到 10–16/24，
**那是拿一种丢字换另一种丢字**。关分块两轮只漏 1 次。

## 三、① 兜底：这条路径以前是纯蒸发

真机日志，规则三（目标应用改变）：

```
22:24:09.557  注入失败，已写入剪贴板：targetApplicationChanged(
                expected: "com.apple.Terminal", actual: "com.apple.systempreferences")
                文本(35字): 测试目标应用改变时候的解贴板兜地…
22:24:09.560  通知未授权（denied），退回 HUD 提示：文字未输入，已复制（⌘V）
```

用户 ⌘V 粘出了那句话。**M6 之前这里只有一行「会话出错」，文字直接没了。**

修好通知授权后重测：

```
22:32:26.340  注入失败，已写入剪贴板：targetApplicationChanged(
                expected: "com.apple.Terminal", actual: "com.google.Chrome")
                文本(10字): 测试通知有没有出来？
```

**「通知未授权，退回 HUD」那一行消失了**——它只在退路上记录，消失即说明
走的是通知本身。用户确认看到了横幅。

### 通知曾经被系统拒绝，原因是设置里关着

`UNErrorDomain Code=1 "Notifications are not allowed for this application"`。
系统设置里 vInput **在列但开关是关的**，所以 `requestAuthorization` 直接
返回 denied、也从不弹框。用户手动打开后即恢复。

**排查时走过的弯路**：先怀疑是从 OneDrive 同步目录运行导致的，于是把 app
复制到 `~/Applications` 试——结果**模型全找不到**（`可用模型=[]`，
退回 `openai_whisper-base`），因为模型路径是相对仓库解析的。已回退。
教训：换位置运行会同时改变多个变量，不是干净的对照。

## 四、⑤ 标点：范围比原计划宽，但句号刻意不做

做了：**逗号、问号、叹号、冒号、分号、成对括号**。

**句号刻意不做**：`我想想...` 的三个点各自都满足邻居规则，转完是
「我想想。。。」。要做得先加省略号保护。

**不能靠改 prompt 修**：`WhisperKitTranscriber.swift` 记着——prompt 里用
全角逗号会触发字节级乱码，24 秒音频上稳定复现，换半角后 90 次转写零乱码。

判据是**看离标点最近的实字符（跳过空白），两侧任一是中文语境就转**。
括号例外，必须**成对**判断三条同时满足，因为 `函数 foo(x) 的返回值` 里
左括号前邻是拉丁、右括号后邻是汉字，**邻居规则会把一对括号拆成一半一全**。

真机实证：

```
先跑 npm install，再跑 pnpm build。          ← 逗号全角，命令内部不动
明天深圳会下雨吗？你帮我查一下天气预报。      ← 问号全角
```

基准集 26 条：**中文语境半角标点 0**。

### 已知误伤，已用测试钉住

`写成 int x = 1; 然后编译` → `1；然后编译`。它和 `部署到 AWS,先跑 npm
install`（该转）**形状一模一样，只看邻居分不开**。括号靠成对判断绕开了，
`; :` 没有「对」可配。测试 `knownFalsePositiveOnTrailingSemicolon` 钉住此
行为，真出问题时先收窄分号与冒号。

## 五、④ 固定签名身份：证书早就在，只差被标记为可信

`codesign` 一直能用这个身份签名，但 `security find-identity -v -p
codesigning` 报 `0 valid identities found`——不带 `-v` 才露出真相：
`CSSMERR_TP_NOT_TRUSTED`。而 `build-app.sh` 恰恰用 `-v` 判断，于是一路
静默退回 ad-hoc。

用户执行 `security add-trusted-cert` 后：

```
designated => identifier "com.vinput.app" and certificate leaf = H"217a6a22…cd15"
```

**TCC 按这个 designated requirement 认应用。** 以前是内容哈希，改一行代码
就是「另一个应用」；现在锚在证书指纹上，证书十年有效。

打包后真机日志 `HID 监听已启动` / `按键抑制器已启动`——授权未被作废。

**PEM 文件曾经丢失**，可从钥匙串重新导出，无需重建证书：

```bash
security find-certificate -c "vInput Dev" -p > ~/.config/vinput/dev-signing-cert.pem
```

## 六、基准集：技术类那一格的分辨力回来了

补录三条**术语刻意不写进 prompt** 的技术样本（M5 独立验收 B1 结转）。
26 条实测：

| | 术语命中率 |
|---|---|
| 点名的（tech-01…06） | **1.00** 全对 |
| **留出的**（tech-hold-01/02/03） | **0.67 / 0.40 / 0.67**，均值 ≈ **0.58** |

错法正是 M4 时代的原病：`Datadog`→`Data Dog`、`useMemo`→`use memo`、
`selector`→`select`、`Vite`→`white`、`tsconfig`→`tsconfigure`、
`paths`→`pathes`。

**用真人录音证实了独立验收的结论**：此前技术类命中率恒为 1.000，量的是
「prompt 里有没有这个词」而非模型能力。合成语料当时预测未点名时技术类
CER 0.0584，真实录音是 **0.084**，方向一致且更差。

**关分块零退化**：punctuation 0.0105、homophone 0.0294、colloquial 0.0093,
三类与改动前**一位小数都没变**——印证「30 秒以下不触发分块」。总体 CER
0.0190 → 0.0264 是因为加了三条更难的样本，原六条技术样本数字未动。

## 八、未竟事项

见 `docs/Roadmap.md` 的「过程中攒下的待办」。M6 期间**新增**的：

- **`vendor/` 整个在 `.gitignore` 里**：WhisperKit 的本地改动不进版本库、
  换机器就丢、没有任何机制能发现。本轮有子代理为取数据往 vendor 加过临时
  探针再手工恢复——**恢复对了是运气好**。
- **`ClipboardSink.send` 的成功路径仍可能丢字**：写剪贴板 + ⌘V + 0.6 秒后
  恢复原内容。目标应用没真正响应那次 ⌘V 时 `send` 不抛错，会话按成功处理，
  0.6 秒后剪贴板被还原，文字就没了。与 ① 同类，但发生在「成功」路径上，
  本轮兜底够不着。
- **误触语音键会注入一个孤零零的句号**：实测 0.197 秒的误碰通过了
  `minimumDuration = 0.15`，模型在几乎无内容的音频上吐出「。」。
- **`TranscriptCleaner` 两处过滤漏洞**：`请不吝点赞\s*订阅` 的正则被一个
  ASR 错字击穿（实际吐的是 `请不吝点赞 讨订阅`）；温度 0 的裸「谢谢。」
  两道过滤都穿得过。**注意裸「谢谢」不能无条件过滤**——它是本应用最高频
  的真实输入之一。
- **几分钟量级录音的覆盖率存疑**：`--scaling` 那轮的数字是**合成产物**
  （把一段话重复拼接，撞上 `compressionRatioThreshold = 2.4`），
  不是结论。需非重复语料 + 多次采样复测。
- **写剪贴板会覆盖用户原有内容**：当前决定是直接覆盖 + 通知告知。是否
  改成「仅在剪贴板为空或内容是我们上次写的时才覆盖」未定。

**M6 验收标准达成。** 主路径上的三条静默丢字全部堵上：超 30 秒整块丢字、
