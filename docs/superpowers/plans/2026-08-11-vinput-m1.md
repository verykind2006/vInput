# vInput M1 实施计划：骨架 + 内置麦 + 转写 + 注入

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付一个可用的 macOS 听写工具——按下全局快捷键说一句话，本地 Whisper 转写后把文字注入当前光标处。

**Architecture:** 五层流水线中的四层（音频源 → 会话 → 转写 → 输出），每层之间只通过 protocol 通信。M1 不含蓝牙、不含 LLM 润色、不含 HUD——这些分别是 M3、M4、M2 的内容。核心内部音频格式统一为 `[Float]`，16 kHz 单声道，取值范围 -1…1。

**Tech Stack:** Swift 6.3 / SwiftUI / SPM（无 Xcode 工程文件）、AVFoundation（麦克风采集与重采样）、WhisperKit（Core ML 转写）、Carbon HIToolbox（全局快捷键）、CoreGraphics Event（文本注入）。

**上位文档：** [`docs/superpowers/specs/2026-08-11-vinput-design.md`](../specs/2026-08-11-vinput-design.md)

### 已知并已解决：`swift test` 在纯 CLT 下不可用

Task 1 执行时实测发现：直接运行 `swift test` 会报 `no such module 'Testing'`。原因是 Swift Testing 的 `Testing.framework` 与 `lib_TestingInterop.dylib` 确实存在于 `$(xcode-select -p)/Library/Developer/` 下，但纯 Command Line Tools 不会把它们加入默认的 framework 搜索路径与 rpath（完整 Xcode 会）。

解决方案是 `scripts/test.sh`——它探测到该情形时补上路径，装了完整 Xcode 时自动退回原生行为。**本计划中所有测试命令一律使用 `./scripts/test.sh`，不要直接用 `swift test`。** 参数原样透传，例如 `./scripts/test.sh --filter AudioBuffer`。

### 分层依赖方向

```
AppModel
  ├─→ HotkeyRegistrar
  ├─→ Permissions
  └─→ DictationSession
         ├─→ AudioSource     (protocol)  ←── SystemMicSource
         ├─→ AudioBuffer     (值类型)
         ├─→ Transcriber     (protocol)  ←── WhisperKitTranscriber
         ├─→ TargetAppGuard
         └─→ TextSink        (protocol)  ←── RoutingTextSink ──→ TypingSink
                                                             └─→ ClipboardSink
```

`DictationSession` 只认识三个 protocol，不认识任何具体实现——这是它能被完整单元测试的原因。

- [ ] **Step 5: 写打包脚本**

SPM 只产出一个裸可执行文件。macOS 要求 TCC 权限（麦克风、辅助功能）必须由一个带 Info.plist 的 `.app` bundle 申请——裸可执行文件申请不到。所以每次测试都得走这个脚本。

创建 `scripts/build-app.sh`：

```bash
#!/bin/zsh
set -euo pipefail

ROOT="${0:A:h:h}"
APP_NAME="vInput"
CONFIGURATION="${CONFIGURATION:-debug}"
APP_DIR="$ROOT/dist/$APP_NAME.app"

cd "$ROOT"
swift build -c "$CONFIGURATION"
BIN_PATH="$(swift build -c "$CONFIGURATION" --show-bin-path)/$APP_NAME"

case "$APP_DIR" in
  "$ROOT/dist/"*.app) ;;
  *) print -u2 "拒绝清理非预期路径: $APP_DIR"; exit 1 ;;
esac

rm -rf -- "$APP_DIR"
mkdir -p "$APP_DIR/Contents/MacOS" "$APP_DIR/Contents/Resources"
ditto --norsrc --noextattr --noqtn --noacl "$BIN_PATH" "$APP_DIR/Contents/MacOS/$APP_NAME"
ditto --norsrc --noextattr --noqtn --noacl "$ROOT/Resources/Info.plist" "$APP_DIR/Contents/Info.plist"

# 临时签名（ad-hoc）。TCC 授权绑定签名，因此每次重新签名后
# 都需要在系统设置里重新勾选辅助功能权限。
codesign --force --sign - --timestamp=none "$APP_DIR"

print "已构建: $APP_DIR"
```

```swift
import Foundation

/// 累积单声道浮点音频样本。取值范围 -1…1。
///
/// 这是纯值类型，不持有任何系统资源，因此可以自由复制与测试。
struct AudioBuffer {
    let sampleRate: Double
    private(set) var samples: [Float] = []

    init(sampleRate: Double) {
        self.sampleRate = sampleRate
    }

    /// 已累积音频的时长（秒）。
    var duration: TimeInterval {
        guard sampleRate > 0 else { return 0 }
        return Double(samples.count) / sampleRate
    }

    mutating func append(_ newSamples: [Float]) {
        samples.append(contentsOf: newSamples)
    }

    /// 返回最近 `lastSeconds` 秒的样本。样本不足则返回全部。
    func window(lastSeconds: TimeInterval) -> [Float] {
        let wanted = Int(lastSeconds * sampleRate)
        guard wanted > 0, samples.count > wanted else { return samples }
        return Array(samples.suffix(wanted))
    }

    mutating func reset() {
        samples.removeAll(keepingCapacity: true)
    }
}
```

```swift
import AVFoundation
import Foundation

/// 从系统默认输入设备采集音频，并统一转换为 16 kHz 单声道 Float32。
@MainActor
final class SystemMicSource: AudioSource {
    var onFrame: (([Float]) -> Void)?
    var onStop: ((Error?) -> Void)?

    private let engine = AVAudioEngine()
    private var converter: AVAudioConverter?
    private var isRunning = false

    private let targetFormat = AVAudioFormat(
        commonFormat: .pcmFormatFloat32,
        sampleRate: AudioFormat.sampleRate,
        channels: 1,
        interleaved: false
    )!

    func start() throws {
        guard !isRunning else { return }

        let input = engine.inputNode
        let inputFormat = input.outputFormat(forBus: 0)
        guard inputFormat.sampleRate > 0 else {
            // 无可用输入设备时 AVAudioEngine 会返回采样率 0 的格式。
            throw AudioSourceError.unsupportedInputFormat(sampleRate: inputFormat.sampleRate)
        }
        guard let converter = AVAudioConverter(from: inputFormat, to: targetFormat) else {
            throw AudioSourceError.unsupportedInputFormat(sampleRate: inputFormat.sampleRate)
        }
        self.converter = converter

        // tap 回调运行在音频线程，不能从那里访问本类型的 @MainActor
        // 属性。因此把目标格式先取到局部常量再捕获。
        let format = targetFormat
        input.installTap(onBus: 0, bufferSize: 4_096, format: inputFormat) { [weak self] buffer, _ in
            guard let converted = SystemMicSource.resample(
                buffer, using: converter, to: format
            ) else { return }
            Task { @MainActor [weak self] in
                self?.onFrame?(converted)
            }
        }

        engine.prepare()
        do {
            try engine.start()
        } catch {
            input.removeTap(onBus: 0)
            throw AudioSourceError.engineFailedToStart(error.localizedDescription)
        }
        isRunning = true
    }

    func stop() {
        guard isRunning else { return }
        engine.inputNode.removeTap(onBus: 0)
        engine.stop()
        converter = nil
        isRunning = false
        onStop?(nil)
    }

    // MARK: - 重采样

    /// 把任意格式的 buffer 转换成目标格式，返回浮点样本数组。
    ///
    /// 抽成静态方法是为了能用合成 buffer 单元测试，无需真实麦克风。
    nonisolated static func resample(
        _ buffer: AVAudioPCMBuffer,
        using converter: AVAudioConverter,
        to format: AVAudioFormat
    ) -> [Float]? {
        guard buffer.frameLength > 0 else { return [] }

        let ratio = format.sampleRate / buffer.format.sampleRate
        let capacity = AVAudioFrameCount(Double(buffer.frameLength) * ratio) + 1_024
        guard let output = AVAudioPCMBuffer(pcmFormat: format, frameCapacity: capacity) else {
            return nil
        }

        // 输入块只能被消费一次，第二次调用要报 noDataNow 让转换器收尾。
        var consumed = false
        var conversionError: NSError?
        let status = converter.convert(to: output, error: &conversionError) { _, outStatus in
            if consumed {
                outStatus.pointee = .noDataNow
                return nil
            }
            consumed = true
            outStatus.pointee = .haveData
            return buffer
        }

        guard status != .error, conversionError == nil else { return nil }
        guard let channel = output.floatChannelData?[0] else { return nil }
        return Array(UnsafeBufferPointer(start: channel, count: Int(output.frameLength)))
    }
}
```

```swift
import Foundation
import WhisperKit

/// WhisperKit 适配层。
///
/// 用 actor 而非 class，是因为模型加载与推理都不可重入：
/// 两个会话同时触发时，第二个必须排队而不是并发进入 Core ML。
actor WhisperKitTranscriber: Transcriber {
    /// 低于此时长的音频不送去转写，避免 Whisper 对极短片段产生幻觉文本。
    static let minimumDuration: TimeInterval = 0.3

    private let modelName: String
    private let language: String
    private var pipe: WhisperKit?

    init(modelName: String = "base", language: String = "zh") {
        self.modelName = modelName
        self.language = language
    }

    func prepare() async throws {
        guard pipe == nil else { return }
        do {
            pipe = try await WhisperKit(WhisperKitConfig(model: modelName))
        } catch {
            throw TranscribeError.engineFailed(error.localizedDescription)
        }
    }

    func transcribe(_ samples: [Float]) async throws -> String {
        let duration = Double(samples.count) / AudioFormat.sampleRate
        guard duration >= Self.minimumDuration else {
            throw TranscribeError.audioTooShort
        }

        try await prepare()
        guard let pipe else { throw TranscribeError.modelNotReady }

        do {
            let options = DecodingOptions(language: language)
            let results = try await pipe.transcribe(
                audioArray: samples,
                decodeOptions: options
            )
            return results
                .map(\.text)
                .joined()
                .trimmingCharacters(in: .whitespacesAndNewlines)
        } catch {
            throw TranscribeError.engineFailed(error.localizedDescription)
        }
    }
}
```

```swift
import ApplicationServices
import CoreGraphics
import Foundation

/// 通过合成键盘事件把文本送进当前焦点输入框。
///
/// 使用 `CGEventKeyboardSetUnicodeString` 而非逐个键码，
/// 因此不依赖当前输入法，中文与 emoji 都能直接送出。
@MainActor
struct TypingSink: TextSink {
    /// 每个事件携带的 UTF-16 单元数。
    /// 太大部分应用会截断，太小则整体变慢。20 是经验上的平衡点。
    var chunkSize: Int = 20

    /// 块之间的间隔。给接收方的事件循环留出处理时间，
    /// 否则终端与部分 Electron 应用会丢字或乱序。
    var interChunkDelay: TimeInterval = 0.004

    /// 可注入，便于测试时绕开真实的权限检查。
    var isAccessibilityTrusted: () -> Bool = { AXIsProcessTrusted() }

    func send(_ text: String) throws {
        guard !text.isEmpty else { return }
        guard isAccessibilityTrusted() else {
            throw TextSinkError.accessibilityDenied
        }

        let units = Array(text.utf16)
        let ranges = Self.chunkRanges(
            unitCount: units.count,
            chunkSize: chunkSize,
            units: units
        )

        for (index, range) in ranges.enumerated() {
            var chunk = Array(units[range])

            guard
                let down = CGEvent(keyboardEventSource: nil, virtualKey: 0, keyDown: true),
                let up = CGEvent(keyboardEventSource: nil, virtualKey: 0, keyDown: false)
            else {
                throw TextSinkError.eventCreationFailed
            }

            down.keyboardSetUnicodeString(stringLength: chunk.count, unicodeString: &chunk)
            up.keyboardSetUnicodeString(stringLength: chunk.count, unicodeString: &chunk)
            down.post(tap: .cgSessionEventTap)
            up.post(tap: .cgSessionEventTap)

            if index < ranges.count - 1 {
                Thread.sleep(forTimeInterval: interChunkDelay)
            }
        }
    }

    // MARK: - 分块

    /// 把 UTF-16 单元序列切成不超过 `chunkSize` 的若干段，
    /// 并保证不在代理对中间切开。
    ///
    /// 抽成 nonisolated 静态纯函数以便单元测试——它不碰任何
    /// 主线程状态，测试无需 @MainActor 隔离即可直接调用。
    nonisolated static func chunkRanges(
        unitCount: Int,
        chunkSize: Int,
        units: [UInt16]
    ) -> [Range<Int>] {
        guard unitCount > 0, chunkSize > 0 else { return [] }

        var ranges: [Range<Int>] = []
        var start = 0
        while start < unitCount {
            var end = min(start + chunkSize, unitCount)
            // 若边界落在高位代理上，把它让给下一块。
            if end < unitCount, isHighSurrogate(units[end - 1]) {
                end -= 1
            }
            // 退化保护：单个代理对本身超过块大小时，至少推进一个单元。
            if end <= start { end = min(start + chunkSize, unitCount) }
            ranges.append(start..<end)
            start = end
        }
        return ranges
    }

    nonisolated private static func isHighSurrogate(_ unit: UInt16) -> Bool {
        (0xD800...0xDBFF).contains(unit)
    }
}
```

```swift
import AppKit
import ApplicationServices
import CoreGraphics
import Foundation

/// 剪贴板读写的最小抽象，便于测试时替换掉全局单例。
protocol PasteboardWriting: AnyObject {
    func string() -> String?
    func write(_ value: String)
}

/// 包装 NSPasteboard.general。
final class SystemPasteboard: PasteboardWriting {
    private let pasteboard = NSPasteboard.general

    func string() -> String? {
        pasteboard.string(forType: .string)
    }

    func write(_ value: String) {
        pasteboard.clearContents()
        pasteboard.setString(value, forType: .string)
    }
}

/// 通过剪贴板 + Cmd+V 输入文本。
///
/// 用于两种情形：文本过长（逐字符注入不可靠），
/// 以及 TypingSink 失败后的降级。
@MainActor
struct ClipboardSink: TextSink {
    /// 粘贴到恢复原内容之间的等待时长。
    /// 太短会在目标应用读取剪贴板之前就恢复，导致粘贴到旧内容。
    var restoreDelay: TimeInterval = 0.6

    var isAccessibilityTrusted: () -> Bool = { AXIsProcessTrusted() }
    var sendPasteShortcut: () -> Void = ClipboardSink.postCommandV

    private let pasteboard: PasteboardWriting
    /// 待恢复的状态：(我们写入的内容, 原有内容)
    private let pending = PendingRestore()

    init(pasteboard: PasteboardWriting = SystemPasteboard()) {
        self.pasteboard = pasteboard
    }

    func send(_ text: String) throws {
        guard !text.isEmpty else { return }
        guard isAccessibilityTrusted() else {
            throw TextSinkError.accessibilityDenied
        }

        let previous = pasteboard.string()
        pasteboard.write(text)
        pending.set(written: text, previous: previous)

        sendPasteShortcut()

        let delay = restoreDelay
        if delay > 0 {
            Task { @MainActor in
                try? await Task.sleep(for: .seconds(delay))
                performPendingRestore()
            }
        }
    }

    /// 恢复原剪贴板内容。仅当剪贴板仍是我们写入的那份时才执行——
    /// 否则说明用户在这期间复制了别的东西，不应覆盖。
    func performPendingRestore() {
        guard let state = pending.take() else { return }
        guard pasteboard.string() == state.written else { return }
        if let previous = state.previous {
            pasteboard.write(previous)
        } else {
            pasteboard.write("")
        }
    }

    /// nonisolated：CGEvent 的发送是线程安全的，且它要作为
    /// 非隔离闭包类型 `() -> Void` 的默认值使用。
    nonisolated private static func postCommandV() {
        let vKeyCode: CGKeyCode = 9  // kVK_ANSI_V
        guard
            let down = CGEvent(keyboardEventSource: nil, virtualKey: vKeyCode, keyDown: true),
            let up = CGEvent(keyboardEventSource: nil, virtualKey: vKeyCode, keyDown: false)
        else { return }
        down.flags = .maskCommand
        up.flags = .maskCommand
        down.post(tap: .cgSessionEventTap)
        up.post(tap: .cgSessionEventTap)
    }
}

/// 承载待恢复状态。用引用类型是因为 ClipboardSink 是 struct，
/// 而 send 需要在其后的异步闭包里读到写入的状态。
@MainActor
private final class PendingRestore {
    struct State {
        let written: String
        let previous: String?
    }

    private var state: State?

    func set(written: String, previous: String?) {
        state = State(written: written, previous: previous)
    }

    func take() -> State? {
        defer { state = nil }
        return state
    }
}
```

注意：`ClipboardSink` 里 `pending` 是 `let` 持有的引用类型，因此 `send` 与 `performPendingRestore` 都声明为非 `mutating` —— 这让它能满足 `TextSink` protocol（其 `send` 不是 `mutating`）。

```swift
import Foundation

/// 在打字与剪贴板两条输入通道之间路由。
///
/// 路由规则：
/// - 长度超过阈值 → 剪贴板（逐字符注入长文本在终端与 Electron 中不可靠）

@MainActor
struct RoutingTextSink: TextSink {
    let typing: TextSink
    let clipboard: TextSink
    /// 超过该字符数改走剪贴板。见 spec 第六节规则三。
    var threshold: Int = 100

    func send(_ text: String) throws {
        if text.count > threshold {
            try clipboard.send(text)
            return
        }

        do {
            try typing.send(text)
        } catch {
            try clipboard.send(text)
        }
    }
}
```

```swift
/// 确保文本注入到会话开始时那个应用，而不是中途抢占焦点的应用。
///
/// 防范的是最严重的失败模式：用户在编辑器里口述，

    func verify(_ token: String?) throws {

        let current = frontmostBundleID()
        guard current == token else {
            throw TextSinkError.targetApplicationChanged(expected: token, actual: current)
        }
    }
}
```

```swift
import Foundation

/// 一次听写会话的完整生命周期。
///
/// 只依赖 AudioSource、Transcriber、TextSink 三个 protocol，
/// 因此可以在不碰麦克风、模型和系统事件的情况下被完整测试。
@MainActor
final class DictationSession {
    enum State: Equatable {
        case idle
        case listening
        case transcribing
        case injecting
    }

    private(set) var state: State = .idle

    /// 状态变化回调，供 UI 更新。
    var onStateChange: ((State) -> Void)?
    /// 任一环节出错时回调。会话本身总会回到 idle。
    var onError: ((Error) -> Void)?
    /// 成功注入后回调，携带最终文本。
    var onText: ((String) -> Void)?

    private let audioSource: AudioSource
    private let transcriber: Transcriber
    private let sink: TextSink
    private let targetGuard: TargetAppGuard

    private var buffer = AudioBuffer(sampleRate: AudioFormat.sampleRate)
    private var targetToken: String?
    /// 转写失败时保留的音频，供 retry 使用。
    private var retainedSamples: [Float] = []

    /// 供测试断言保留的样本数。
    var retainedSampleCount: Int { retainedSamples.count }

    init(
        audioSource: AudioSource,
        transcriber: Transcriber,
        sink: TextSink,
        targetGuard: TargetAppGuard
    ) {
        self.audioSource = audioSource
        self.transcriber = transcriber
        self.sink = sink
        self.targetGuard = targetGuard

        audioSource.onFrame = { [weak self] samples in
            self?.buffer.append(samples)
        }
        audioSource.onStop = { [weak self] error in
            guard let self, let error else { return }
            // 采集过程中出错：终止会话，已收到的音频丢弃
            // （M1 不做部分转写；M3 蓝牙断连场景会重新审视）。
            self.transition(to: .idle)
            self.onError?(error)
        }
    }

    // MARK: - 生命周期

    /// 开始采集。重复调用会被忽略。
    func start() throws {
        guard state == .idle else { return }

        buffer.reset()
        retainedSamples = []
        targetToken = targetGuard.capture()

        try audioSource.start()
        transition(to: .listening)
    }

    /// 结束采集并走完转写与注入。
    func finish() async {
        guard state == .listening else { return }

        audioSource.stop()
        let samples = buffer.samples
        buffer.reset()

        await process(samples)
    }

    /// 用上一次失败时保留的音频重新走一遍。
    func retry() async {
        guard state == .idle, !retainedSamples.isEmpty else { return }
        let samples = retainedSamples
        await process(samples)
    }

    // MARK: - 处理

    private func process(_ samples: [Float]) async {
        guard !samples.isEmpty else {
            transition(to: .idle)
            return
        }

        transition(to: .transcribing)

        let text: String
        do {
            text = try await transcriber.transcribe(samples)
        } catch {
            // 规则二：保留音频，允许重试
            retainedSamples = samples
            transition(to: .idle)
            onError?(error)
            return
        }

        retainedSamples = []

        let trimmed = text.trimmingCharacters(in: .whitespacesAndNewlines)
        guard !trimmed.isEmpty else {
            transition(to: .idle)
            return
        }

        transition(to: .injecting)

        do {
            // 规则三：注入前确认目标应用没变
            try targetGuard.verify(targetToken)
            try sink.send(trimmed)
            onText?(trimmed)
        } catch {
            onError?(error)
        }

        transition(to: .idle)
    }

    private func transition(to newState: State) {
        guard state != newState else { return }
        state = newState
        onStateChange?(newState)
    }
}
```

```swift
import Carbon.HIToolbox
import Foundation

/// 热键 ID 到 Swift 闭包的映射。
///
/// Carbon 的事件处理器是 C 函数指针，无法捕获上下文，
/// 只能拿到一个整数 ID，因此需要这张表做转发。
@MainActor
final class HotkeyCallbackTable {
    static let shared = HotkeyCallbackTable()

    private var handlers: [UInt32: () -> Void] = [:]
    private var nextID: UInt32 = 1

    func register(_ handler: @escaping () -> Void) -> UInt32 {
        let id = nextID
        nextID += 1
        handlers[id] = handler
        return id
    }

    func unregister(_ id: UInt32) {
        handlers.removeValue(forKey: id)
    }

    func dispatch(_ id: UInt32) {
        handlers[id]?()
    }
}

enum HotkeyError: Error, Equatable {
    case registrationFailed(OSStatus)
    case handlerInstallFailed(OSStatus)
}

/// 一个全局快捷键的注册与生命周期管理。
///
/// 使用 Carbon `RegisterEventHotKey`，不需要「输入监控」权限。
@MainActor
final class HotkeyRegistrar {
    /// 应用签名，用于区分不同应用注册的热键。'vINP'
    private static let signature: OSType = 0x76_49_4E_50

    private var hotKeyRef: EventHotKeyRef?
    private var eventHandler: EventHandlerRef?
    private var callbackID: UInt32?

    /// 注册快捷键。
    /// - Parameters:
    ///   - keyCode: Carbon 虚拟键码，例如 `UInt32(kVK_ANSI_D)`
    ///   - modifiers: Carbon 修饰键掩码，例如 `UInt32(optionKey | cmdKey)`
    func register(
        keyCode: UInt32,
        modifiers: UInt32,
        handler: @escaping () -> Void
    ) throws {
        unregister()

        let id = HotkeyCallbackTable.shared.register(handler)
        callbackID = id

        var eventType = EventTypeSpec(
            eventClass: OSType(kEventClassKeyboard),
            eventKind: UInt32(kEventHotKeyPressed)
        )

        let installStatus = InstallEventHandler(
            GetApplicationEventTarget(),
            { _, event, _ -> OSStatus in
                var pressedID = EventHotKeyID()
                let status = GetEventParameter(
                    event,
                    EventParamName(kEventParamDirectObject),
                    EventParamType(typeEventHotKeyID),
                    nil,
                    MemoryLayout<EventHotKeyID>.size,
                    nil,
                    &pressedID
                )
                guard status == noErr else { return status }
                let identifier = pressedID.id
                // Carbon 回调在主线程，但编译器不知道，显式跳一次。
                DispatchQueue.main.async {
                    MainActor.assumeIsolated {
                        HotkeyCallbackTable.shared.dispatch(identifier)
                    }
                }
                return noErr
            },
            1,
            &eventType,
            nil,
            &eventHandler
        )
        guard installStatus == noErr else {
            HotkeyCallbackTable.shared.unregister(id)
            callbackID = nil
            throw HotkeyError.handlerInstallFailed(installStatus)
        }

        let hotKeyID = EventHotKeyID(signature: Self.signature, id: id)
        let registerStatus = RegisterEventHotKey(
            keyCode,
            modifiers,
            hotKeyID,
            GetApplicationEventTarget(),
            0,
            &hotKeyRef
        )
        guard registerStatus == noErr else {
            unregister()
            throw HotkeyError.registrationFailed(registerStatus)
        }
    }

    func unregister() {
        if let hotKeyRef {
            UnregisterEventHotKey(hotKeyRef)
            self.hotKeyRef = nil
        }
        if let eventHandler {
            RemoveEventHandler(eventHandler)
            self.eventHandler = nil
        }
        if let callbackID {
            HotkeyCallbackTable.shared.unregister(callbackID)
            self.callbackID = nil
        }
    }

    deinit {
        // deinit 不能进 MainActor，交给显式的 unregister()。
        // AppModel 负责在退出前调用。
    }
}
```

```swift
import AVFoundation
import AppKit
import ApplicationServices
import Foundation

/// 应用运行所需的两项系统权限。
///
/// 不需要「输入监控」——全局快捷键走 Carbon RegisterEventHotKey，
/// 该 API 无隐私授权要求。
struct Permissions {
    enum Status: Equatable {
        case ready
        case microphoneMissing
        case accessibilityMissing
    }

    var microphoneAuthorized: () -> Bool = {
        AVCaptureDevice.authorizationStatus(for: .audio) == .authorized
    }

    var accessibilityTrusted: () -> Bool = {
        AXIsProcessTrusted()
    }

    func status() -> Status {
        // 麦克风优先：没有它连录音都开始不了。
        guard microphoneAuthorized() else { return .microphoneMissing }
        guard accessibilityTrusted() else { return .accessibilityMissing }
        return .ready
    }

    /// 弹出系统麦克风授权对话框。
    func requestMicrophone() async -> Bool {
        await AVCaptureDevice.requestAccess(for: .audio)
    }

    /// 打开「系统设置 → 隐私与安全性 → 辅助功能」。
    ///
    /// 辅助功能无法通过 API 申请，只能引导用户手动勾选。
    @MainActor
    func openAccessibilitySettings() {
        let url = URL(
            string: "x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility"
        )!
        NSWorkspace.shared.open(url)
    }
}
```

```swift
            sink: RoutingTextSink(
                typing: TypingSink(),
                clipboard: ClipboardSink(),
                threshold: 100
            ),
            targetGuard: TargetAppGuard()
        )

        session.onStateChange = { [weak self] state in
            guard let self else { return }
            switch state {
            case .idle: self.phase = .idle
            case .listening: self.phase = .listening
            case .transcribing, .injecting: self.phase = .working
            }
        }
        session.onError = { [weak self] error in
            self?.phase = .error(String(describing: error))
        }
        session.onText = { [weak self] text in
            self?.lastText = text
        }
        self.session = session

        do {
            try hotkey.register(keyCode: hotkeyCode, modifiers: hotkeyModifiers) { [weak self] in
                self?.toggle()
            }
        } catch {
            phase = .error("快捷键注册失败：\(error)")
        }
    }

    func shutdown() {
        hotkey.unregister()
    }

    /// 快捷键触发：未在录音则开始，正在录音则结束。
    func toggle() {
        guard let session else { return }

        permissionStatus = permissions.status()
        guard permissionStatus == .ready else {
            handleMissingPermission()
            return
        }

        switch session.state {
        case .idle:
            do {
                try session.start()
            } catch {
                phase = .error(String(describing: error))
            }
        case .listening:
            Task { await session.finish() }
        case .transcribing, .injecting:
            // 正在处理上一段，忽略。
            break
        }
    }

    private func handleMissingPermission() {
        switch permissionStatus {
        case .microphoneMissing:
            Task {
                _ = await permissions.requestMicrophone()
                permissionStatus = permissions.status()
            }
        case .accessibilityMissing:
            permissions.openAccessibilitySettings()
        case .ready:
            break
        }
    }
}
```

- [ ] **Step 6: 接上菜单栏 UI**

`bootstrap()` 必须在应用启动时执行，而不是等菜单被点开——快捷键要在后台一直可用。因此用 `NSApplicationDelegateAdaptor` 挂到应用生命周期上，**不要**挂在任何视图的 `.onAppear` 上（菜单栏视图只在用户点开菜单时才创建）。

```swift
import AppKit
import SwiftUI

@main
struct vInputApp: App {
    @NSApplicationDelegateAdaptor(AppDelegate.self) private var delegate

    var body: some Scene {
        MenuBarExtra {
            MenuContent(model: delegate.model)
        } label: {
            Image(systemName: iconName)
        }
    }

    private var iconName: String {
        switch delegate.model.phase {
        case .idle: "mic"
        case .listening: "mic.fill"
        case .working: "waveform"
        case .error: "exclamationmark.triangle"
        }
    }
}

/// 承载应用级生命周期。快捷键注册必须在启动时完成，
/// 而不是等用户点开菜单栏——否则后台快捷键在首次点击前不可用。
@MainActor
final class AppDelegate: NSObject, NSApplicationDelegate {
    let model = AppModel()

    func applicationDidFinishLaunching(_ notification: Notification) {
        model.bootstrap()
    }

    func applicationWillTerminate(_ notification: Notification) {
        model.shutdown()
    }
}

private struct MenuContent: View {
    let model: AppModel

    var body: some View {
        Text(statusText)

        if !model.lastText.isEmpty {
            Divider()
            Text("上次：\(model.lastText.prefix(40))")
        }

        Divider()
        Button("开始 / 结束听写  ⌥D") { model.toggle() }
        Divider()
        Button("退出") { NSApplication.shared.terminate(nil) }
            .keyboardShortcut("q")
    }

    private var statusText: String {
        switch model.phase {
        case .idle:
            switch model.permissionStatus {
            case .ready: "就绪"
            case .microphoneMissing: "需要麦克风权限"
            case .accessibilityMissing: "需要辅助功能权限"
            }
        case .listening: "正在聆听…"
        case .working: "正在转写…"
        case .error(let message): "出错：\(message)"
        }
    }
}
```

## 风险与备选

### 风险 1：无完整 Xcode 导致 WhisperKit 无法构建

本机只有 Command Line Tools。若 Task 2 Step 3 失败，按以下顺序考虑备选，**由用户决定**：

1. **安装完整 Xcode** —— 最直接，但需要约 15 GB 磁盘与用户的下载时间
2. **改用 whisper.cpp** —— 纯 C++，不依赖 Core ML 工具链，但需要写桥接层，且失去 ANE 加速
3. **改用系统 `SpeechTranscriber`** —— 见风险 2

### 风险 2：macOS 26 的系统语音识别可能让 Whisper 变得多余

本机运行 macOS 26.5.2，Apple 的 `SpeechAnalyzer` / `SpeechTranscriber` 系统 API 可用。若其中文质量够用，可省掉约 1.5 GB 模型下载、省掉 WhisperKit 依赖、且延迟可能更低。

代价是把最低系统版本从 macOS 14 抬到 26，与 spec 第五节的选型冲突。

**本计划不改变选型。** 建议在 M1 验收（Task 14）拿到 Whisper 的真实中文质量数据后，再花半天做一次并排对比，然后由用户决定是否调整 spec。在此之前不要行动。

### 风险 3：`base` 模型的中文质量可能不足

`AppModel` 里硬编码了 `modelName: "base"`，这是为了让 M1 快速跑通（模型小、下载快）。若 Task 14 的转写质量差到无法判断链路是否正确，改成 `"large-v3-v20240930_turbo"` 重测一次——注意首次下载会显著变长。

模型选择的设置界面属于 M6，M1 不做。

### 风险 4：`AVAudioConverter` 在某些输入设备上返回意外的样本数

Task 5 的测试对偏差容忍到 5%。若在真实设备上偏差更大，不要放宽实现，先确认输入设备的实际格式（`engine.inputNode.outputFormat(forBus: 0)`），可能是多声道设备走了非预期的降混路径。
