# M5 转写质量优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建一套真人语音基准集与对照工具，使任意转写层改动都能一条命令得到量化的前后对比，不必每轮拉用户读一遍。

**Architecture:** 基准集 = 进版本库的 `manifest.json`（标准文本）+ 不进版本库的录音。录制入口做进主应用（复用已有的麦克风授权）。对照工具做成门控的测试套件——它能 `@testable import vInput`，直接跑生产管线，避免复刻带来的参数漂移。

**Tech Stack:** Swift 6 / Swift Testing / AVFoundation（录音与 WAV 写出）/ WhisperKit

---

## 背景：给不熟悉本仓库的工程师

vInput 是 macOS 后台语音输入应用：说话 → 本地 Whisper 转写 → 可选的本地 LLM
校正 → 文字注入光标处。M1–M4 已完成。

**必须用 `./scripts/test.sh` 跑单元测试，不能用 `swift test`**：本机是纯
Command Line Tools 环境，缺 Swift Testing 的框架搜索路径。

**涉及 MLX（校正层）的测试必须走 `xcodebuild`**：SwiftPM 命令行无法编译
mlx-swift 的 Metal 着色器，会崩在 `Failed to load the default metallib`。
见 `docs/dev-dependencies.md`。转写层不受此限，`./scripts/test.sh` 即可。

**两套测试不能并行跑**——会抢构建产物导致测试运行器超时。

**代码注释一律中文**，解释「为什么」而非「是什么」。

### 三条铁律

1. 规则一：场景风格由前台应用决定（M6 的事）
2. **规则二·永不丢字**：任何失败路径都不得让用户已说出的内容消失
3. 规则三：注入前校验目标应用未变

### 为什么要做这件事

M4 收尾时六段标准测试的错误归因：**七个错误里只有一个是下游能修的**，
其余全是转写层的漏字、听错、大小写。而下游看不到音频——Whisper 一旦写出
`collodecode`，声学证据就没了。

但每验证一轮都要拉用户读一遍标准文本，迭代速度受限于用户的时间。
本里程碑就是解决这个瓶颈。

### 已知的坑（别重踩）

- 现有 `/tmp/vinput-bench/*.wav` 是 `say -v Tingting` 合成的，**连真实失败都
  复现不了**（大小写丢失在 TTS 上根本不出现）。所以要建真人基准集。
- `Sources/vInputBench/Bench.swift` 里的转写 shim 曾经与生产差了两个参数
  （`skipSpecialTokens`、`promptTokens`），而注释写着「保持与生产相同」。
  **复刻必然漂移**——本计划因此不走复刻路线。

## 文件结构

| 文件 | 职责 |
|---|---|
| `Bench/manifest.json` | 基准集定义：条目 ID、标准文本、类别。**进版本库** |
| `Bench/audio/*.wav` | 录音。**不进版本库**（`.gitignore`） |
| `Sources/vInput/Bench/BenchManifest.swift` | manifest 的读写与类型 |
| `Sources/vInput/Bench/BenchRecorder.swift` | 录音会话与 WAV 写出 |
| `Sources/vInput/Bench/BenchMetrics.swift` | CER、分类指标、diff（纯函数） |
| `Sources/vInput/App/vInputApp.swift` | 菜单入口（开发期，需环境变量开启） |
| `Tests/vInputTests/BenchRunnerTests.swift` | 对照工具：门控测试，跑全集出报告 |
| `scripts/bench-run.sh` | 对照工具的入口脚本 |

**为什么 `Bench/` 放在 `Sources/vInput/` 下而不是独立目标**：录制要用麦克风，
而 macOS 的 TCC 授权绑定应用 bundle，独立可执行文件拿不到。做进主应用可复用
已有的麦克风授权与 `SystemMicSource`。代价是开发期工具混进产品代码——用
环境变量把入口藏起来，并在注释里标明不随分发。

**为什么对照工具放在测试目标**：它必须跑**生产管线**才有意义。测试目标能
`@testable import vInput`，直接用 `WhisperKitTranscriber` 与
`CorrectionPipeline`，零复刻。`PipelineE2ETests` 已是这个模式。

```swift
        let manifest = try BenchManifest.loadFromRepository()
```

```swift
import Foundation

/// 基准集的类别。
///
/// 四类各有明确职责，缺一类就有一块覆盖不到，而覆盖缺口不会自己叫。
enum BenchCategory: String, Codable, CaseIterable, Sendable {
    /// 技术术语与代码标识符。用户主场景，也是 M4 收尾时错得最惨的一类。
    case technical
    /// 长句与标点。连说 15–30 秒不停顿，守住 initial prompt 已取得的改善。
    case punctuation
    /// 同音陷阱。直接考验校正层，也是判断「换模型/改 prompt 有没有用」的主依据。
    case homophone
    /// 口语与日常表达。验证「不该改的不要改」——**这一类的改动数是硬约束**。
    case colloquial
}

/// 基准集的一条：一段标准文本，对应一段录音。
struct BenchEntry: Codable, Equatable, Sendable {
    /// 同时用作录音文件名（`Bench/audio/<id>.wav`），因此必须唯一。
    let id: String
    /// 标准文本。录制时提示用户照读，对照时作为参考答案。
    let text: String
    let category: BenchCategory
}

struct BenchManifest: Codable, Equatable, Sendable {
    let entries: [BenchEntry]

    /// 仓库内的基准集目录。
    ///
    /// 用 `#filePath` 回溯仓库根，不依赖进程的当前工作目录——`swift test`
    /// 与 `xcodebuild test` 下的 cwd 并不相同（M4 期间踩过）。
    static var repositoryRoot: URL {
        URL(fileURLWithPath: #filePath)
            .deletingLastPathComponent()   // Bench
            .deletingLastPathComponent()   // vInput
            .deletingLastPathComponent()   // Sources
            .deletingLastPathComponent()   // 仓库根
    }

    static var manifestURL: URL {
        repositoryRoot.appendingPathComponent("Bench/manifest.json")
    }

    static var audioDirectory: URL {
        repositoryRoot.appendingPathComponent("Bench/audio", isDirectory: true)
    }

    static func loadFromRepository() throws -> BenchManifest {
        let data = try Data(contentsOf: manifestURL)
        return try JSONDecoder().decode(BenchManifest.self, from: data)
    }

    /// 某条目的录音路径。文件可能不存在（还没录）。
    static func audioURL(for entry: BenchEntry) -> URL {
        audioDirectory.appendingPathComponent("\(entry.id).wav")
    }
}
```

```swift
import AVFoundation
import Foundation
import Testing

@testable import vInput

@Suite("基准集录音写出")
struct BenchRecorderTests {
    private func temporaryURL() -> URL {
        FileManager.default.temporaryDirectory
            .appendingPathComponent("\(UUID().uuidString).wav")
    }

    /// 写出的必须是 Whisper 能直接吃的格式：16 kHz 单声道。
    /// 格式不对的话，基准集测出来的是格式转换的差异，不是模型的差异。
    @Test("写出 16 kHz 单声道 WAV")
    func writesExpectedFormat() throws {
        let url = temporaryURL()
        defer { try? FileManager.default.removeItem(at: url) }

        let samples = [Float](repeating: 0.1, count: 16_000)
        try BenchRecorder.writeWAV(samples: samples, to: url)

        let file = try AVAudioFile(forReading: url)
        #expect(file.fileFormat.sampleRate == AudioFormat.sampleRate)
        #expect(file.fileFormat.channelCount == 1)
        #expect(file.length == 16_000)
    }

    /// 读回来的样本要和写进去的一致，否则基准集本身就失真了。
    @Test("样本往返一致")
    func samplesRoundTrip() throws {
        let url = temporaryURL()
        defer { try? FileManager.default.removeItem(at: url) }

        let samples: [Float] = (0..<1000).map { Float(sin(Double($0) * 0.1)) * 0.5 }
        try BenchRecorder.writeWAV(samples: samples, to: url)

        let readBack = try BenchRecorder.readWAV(from: url)
        #expect(readBack.count == samples.count)
        // Int16 量化后有精度损失，比对到千分之一即可
        for (index, expected) in samples.enumerated() {
            #expect(abs(readBack[index] - expected) < 0.001, "第 \(index) 个样本偏差过大")
        }
    }

    @Test("空样本不写出文件")
    func emptySamplesThrow() {
        let url = temporaryURL()
        #expect(throws: BenchRecorderError.self) {
            try BenchRecorder.writeWAV(samples: [], to: url)
        }
    }
}
```

- [ ] **Step 3: 实现**

创建 `Sources/vInput/Bench/BenchRecorder.swift`：

```swift
import AVFoundation
import Foundation

enum BenchRecorderError: Error, Equatable {
    /// 没有样本可写。录了个寂寞，不该产出一个空文件让人以为录好了。
    case noSamples
    /// 音频格式构造失败。
    case formatUnavailable
}

/// 基准集录音的写出与读回。
///
/// **这是开发期工具，不随应用分发。** 原始设计的隐私一节写明「音频不落盘」，
/// 基准集是那条原则的一个明确例外，范围严格限定：只有录制入口会调到这里，
/// 听写主路径一行代码不改。
enum BenchRecorder {
    /// 写成 16 kHz 单声道 Int16 WAV。
    ///
    /// 格式与 `AudioFormat.sampleRate` 一致，也正是 Whisper 的原生输入格式
    /// ——基准集测的应当是模型的差异，不该混进格式转换的差异。
    static func writeWAV(samples: [Float], to url: URL) throws {
        guard !samples.isEmpty else { throw BenchRecorderError.noSamples }

        let settings: [String: Any] = [
            AVFormatIDKey: kAudioFormatLinearPCM,
            AVSampleRateKey: AudioFormat.sampleRate,
            AVNumberOfChannelsKey: 1,
            AVLinearPCMBitDepthKey: 16,
            AVLinearPCMIsFloatKey: false,
            AVLinearPCMIsBigEndianKey: false,
        ]

        try FileManager.default.createDirectory(
            at: url.deletingLastPathComponent(), withIntermediateDirectories: true
        )
        let file = try AVAudioFile(forWriting: url, settings: settings)

        guard let format = AVAudioFormat(
            standardFormatWithSampleRate: AudioFormat.sampleRate, channels: 1
        ), let buffer = AVAudioPCMBuffer(
            pcmFormat: format, frameCapacity: AVAudioFrameCount(samples.count)
        ) else {
            throw BenchRecorderError.formatUnavailable
        }

        buffer.frameLength = AVAudioFrameCount(samples.count)
        samples.withUnsafeBufferPointer { source in
            buffer.floatChannelData?[0].update(from: source.baseAddress!, count: samples.count)
        }
        try file.write(from: buffer)
    }

    /// 读回样本。用 WhisperKit 的读取器，与生产转写走的是同一条路径。
    static func readWAV(from url: URL) throws -> [Float] {
        try AudioProcessor.loadAudioAsFloatArray(fromPath: url.path)
    }
}
```

**注意**：`readWAV` 用 `AudioProcessor.loadAudioAsFloatArray`，需要
`import WhisperKit`。若编译报找不到，把 import 补上。

```swift
import Foundation

/// 基准集的度量。全部是纯函数，可穷举测试。
///
/// **三层指标缺一不可**：总体的字错误率看全局，分类指标定位「改动影响了
/// 哪一类」，逐段 diff 让人看得见具体错在哪。
///
/// 分类指标不能被总体指标取代：一次改动可能让字错误率微降却把技术词全毁掉。
/// M4 期间就出现过——某个 prompt 变体在多数音频上标点持平，却把两段的标点
/// 砍掉一半。只看一个数会漏掉。
enum BenchMetrics {
    /// 计入字错误率的字符：汉字、字母、数字。
    ///
    /// **标点刻意排除**，由 `punctuationCount` 独立衡量。混在一起的话，
    /// 一次标点改善会掩盖一次真实的漏字。
    static func significantCharacters(_ text: String) -> [Character] {
        text.filter { $0.isLetter || $0.isNumber }
    }

    /// 字错误率：编辑距离 / 参考文本长度。
    ///
    /// 参考文本为空时返回 0（无从判断），假设为空时返回 1（全错）。
    static func characterErrorRate(reference: String, hypothesis: String) -> Double {
        let ref = significantCharacters(reference)
        let hyp = significantCharacters(hypothesis)
        guard !ref.isEmpty else { return 0 }
        return Double(editDistance(ref, hyp)) / Double(ref.count)
    }

    /// Levenshtein 距离。滚动数组实现，只留两行，长文本也不会撑爆内存。
    static func editDistance(_ a: [Character], _ b: [Character]) -> Int {
        guard !a.isEmpty else { return b.count }
        guard !b.isEmpty else { return a.count }

        var previous = Array(0...b.count)
        var current = [Int](repeating: 0, count: b.count + 1)

        for i in 1...a.count {
            current[0] = i
            for j in 1...b.count {
                let cost = a[i - 1] == b[j - 1] ? 0 : 1
                current[j] = min(
                    previous[j] + 1,        // 删除
                    current[j - 1] + 1,     // 插入
                    previous[j - 1] + cost  // 替换
                )
            }
            swap(&previous, &current)
        }
        return previous[b.count]
    }

    /// 中英文标点的个数。
    static func punctuationCount(_ text: String) -> Int {
        text.filter { $0.isPunctuation || $0.isSymbol }.count
    }

    /// 从标准文本里抽出技术词：连续的拉丁字母序列（可含空格连接的多词）。
    ///
    /// 抽而不是手工列表：标准文本改了，词表自动跟着改，不会漏。
    static func technicalTerms(in text: String) -> [String] {
        let pattern = #"[A-Za-z][A-Za-z0-9]*(?: [A-Z][A-Za-z0-9]*)*"#
        guard let regex = try? NSRegularExpression(pattern: pattern) else { return [] }
        let range = NSRange(text.startIndex..., in: text)
        return regex.matches(in: text, range: range).compactMap {
            Range($0.range, in: text).map { String(text[$0]) }
        }
    }

    /// 技术词的命中率。**大小写严格比对**——`github actions` 不算命中，
    /// M4 真机上大小写丢失正是主要失败形态之一。
    static func termHitRate(terms: [String], in text: String) -> Double {
        guard !terms.isEmpty else { return 1.0 }
        let hits = terms.filter { text.contains($0) }.count
        return Double(hits) / Double(terms.count)
    }
}
```

```swift
/// 录制会话的进度状态。
///
/// 抽成独立类型而非塞进 `AppModel`：录制是开发期功能，不该让产品代码
/// 的状态机变复杂；而且这样才能不碰麦克风就把导航逻辑测掉。
@MainActor
@Observable
final class BenchRecordingSession {
    private let manifest: BenchManifest
    private(set) var index = 0

    init(manifest: BenchManifest) {
        self.manifest = manifest
    }

    var current: BenchEntry? {
        manifest.entries.indices.contains(index) ? manifest.entries[index] : nil
    }

    var progressText: String { "\(index + 1) / \(manifest.entries.count)" }

    /// 该条是否已经录过。录制界面据此提示用户哪些还没录。
    var currentIsRecorded: Bool {
        guard let current else { return false }
        return FileManager.default.fileExists(
            atPath: BenchManifest.audioURL(for: current).path
        )
    }

    func advance() {
        index = min(index + 1, manifest.entries.count - 1)
    }

    /// 回到上一条。**必须有**：一次性录完二十几段不允许出错是不现实的。
    func retreat() {
        index = max(index - 1, 0)
    }

    func jump(toID id: String) {
        guard let target = manifest.entries.firstIndex(where: { $0.id == id }) else { return }
        index = target
    }
}
```

import Foundation
import Testing

@testable import vInput

/// 基准集对照运行器。默认跳过，由标记文件启用：
///
/// ```bash
/// ./scripts/bench-run.sh openai_whisper-large-v3-v20240930_turbo
/// ```
///
/// **门控用标记文件而非环境变量**：`xcodebuild test` 不把父进程环境传给
/// 测试运行器，实测会让整个套件被静默跳过而仍报 TEST SUCCEEDED
/// （M4 期间踩过）。转写层虽然用 `swift test` 就能跑，但保持同一种门控
/// 方式可以少一个需要记住的差异。
///
/// **必须串行**：并发跑十几个 Core ML 实例会报
/// `ANE op async execution has timed out`，整片假失败。
@Suite("基准集对照", .enabled(if: BenchRunGate.isEnabled), .serialized)
struct BenchRunnerTests {
    @Test("跑完全集并输出报告")
    func runFullBenchmark() async throws {
        let manifest = try BenchManifest.loadFromRepository()
        let config = try BenchRunGate.config()

        let transcriber = WhisperKitTranscriber(modelFolder: config.modelFolder)
        try await transcriber.prepare()

        var lines: [String] = []
        var totalCER = 0.0
        var counted = 0
        var categoryStats: [BenchCategory: (cer: Double, count: Int)] = [:]

        for entry in manifest.entries {
            let audioURL = BenchManifest.audioURL(for: entry)
            guard FileManager.default.fileExists(atPath: audioURL.path) else {
                lines.append("⬜ \(entry.id) 未录音，跳过")
                continue
            }

            let samples = try BenchRecorder.readWAV(from: audioURL)
            let output = try await transcriber.transcribe(samples)

            let cer = BenchMetrics.characterErrorRate(
                reference: entry.text, hypothesis: output
            )
            totalCER += cer
            counted += 1
            let previous = categoryStats[entry.category] ?? (0, 0)
            categoryStats[entry.category] = (previous.cer + cer, previous.count + 1)

            // 技术词单独看命中率：CER 会把「github actions」算成 13 个字
            // 里错 2 个，看着还行，实际上专名全毁了。分类指标不能被
            // 总体指标取代，这是 M4 用数据换来的教训。
            let terms = BenchMetrics.technicalTerms(in: entry.text)
            let hitNote = terms.isEmpty
                ? ""
                : "  术语=\(String(format: "%.2f", BenchMetrics.termHitRate(terms: terms, in: output)))"

            let mark = cer == 0 ? "✅" : "❌"
            lines.append("""
                \(mark) \(entry.id)  CER=\(String(format: "%.3f", cer))  \
                标点=\(BenchMetrics.punctuationCount(output))\(hitNote)
                   参考：\(entry.text)
                   实际：\(output)
                """)
        }

        #expect(counted > 0, "一条录音都没有——先用 VINPUT_BENCH=1 启动应用录制")

        var report = "模型：\(config.modelFolder ?? "默认")\n"
        report += "样本：\(counted) / \(manifest.entries.count)\n"
        report += "总体 CER：\(String(format: "%.4f", totalCER / Double(counted)))\n\n"
        for category in BenchCategory.allCases {
            guard let stat = categoryStats[category], stat.count > 0 else { continue }
            report += "\(category.rawValue)：CER=\(String(format: "%.4f", stat.cer / Double(stat.count)))"
            report += "（\(stat.count) 条）\n"
        }
        report += "\n" + lines.joined(separator: "\n")

        try report.write(
            to: BenchRunGate.reportURL, atomically: true, encoding: .utf8
        )
        print(report)
    }
}

/// 对照运行的门控与配置。
enum BenchRunGate {
    struct Config: Codable {
        /// Whisper 模型目录的绝对路径。nil 表示用默认。
        let modelFolder: String?
    }

    static var markerURL: URL {
        BenchManifest.repositoryRoot.appendingPathComponent("Bench/.run-config.json")
    }

    static var reportURL: URL {
        BenchManifest.repositoryRoot.appendingPathComponent("Bench/report.txt")
    }

    static var isEnabled: Bool {
        FileManager.default.fileExists(atPath: markerURL.path)
    }

    static func config() throws -> Config {
        try JSONDecoder().decode(Config.self, from: Data(contentsOf: markerURL))
    }
}
