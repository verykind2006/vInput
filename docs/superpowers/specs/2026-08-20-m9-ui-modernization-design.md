# M9 第一批：UI 现代化（HUD、菜单面板、两处图标）

2026-08-20 与用户走完 brainstorming（可视化伴侣四轮选型 + 终端确认）定稿。
**M9 仍是「分发准备」大伞，本批只做 UI 现代化**；设置界面、onboarding 是
M9 后续批次，届时长在本批做出的菜单面板里。

## 已拍板的决策（全部经用户逐项确认）

| 决策点 | 结论 | 落选项 |
|---|---|---|
| 风格方向 | **C · 极简专业**：纯色深底、单一强调色、克制排版 | 深邃玻璃 / 科幻终端 / 能量渐变 |
| 强调色 | **琥珀橙 `#FF9500`**（大尺寸渐变 `#FFB340→#FF8A00`） | 电光青 / 系统蓝 / 荧光绿 |
| 品牌图形 | **V 字声波**：五根声柱排成 V 剪影（V=vInput，声柱=语音） | 递减声柱 / 光标声弧 / V 字负形 |
| 菜单形态 | **自定义面板**（`MenuBarExtra` 切 `.window`） | 保留原生菜单 |
| 设备卡 | **连谁显示谁**（用户原话：「不是每一台机器都会同时连着遥控器和鼠标」） | 常驻两行 |
| 新功能 | HUD 预览文字 **⌘＋/⌘－ 缩放、⌘0 复位**（用户提出） | —— |

## 视觉系统（四块资产共用）

- 面板底 `#1D1D1F`，内容块 `#2A2A2D`，描边 `rgba(255,255,255,0.09)` 发丝线，
  深投影。**纯色深底替换现在的系统毛玻璃**——这是「C 风格」与现状的
  根本区别。
- 唯一强调色琥珀橙 `#FF9500`；App 图标、面板主按钮等大面积处用渐变
  `#FFB340 → #FF8A00`。
- 正文系统字体（苹方/SF），时长、电量等数字一律等宽字体。
- V 字声波 mark 是唯一品牌图形，HUD 不放（它已有波形），菜单面板头部、
  菜单栏图标、App 图标三处共用同一份几何定义。

## ① HUD

**布局结构一律不动**——现有结构（状态条/文本框/附注/按键提示、固定高度、
head 截断、已确认+未确认双色）全是真机反馈磨出来的，只换视觉：

- 背景：`regularMaterial` → `#1D1D1F` 纯色 + 发丝描边 + 投影，圆角 16→14。
- 文本框：`textBackgroundColor.opacity(0.55)` → `#2A2A2D`。
- 状态点与波形：听写中琥珀橙（原红/默认色）；处理中波形停走、点转灰；
  出错时状态文字转红。语义分档不变（idle/listening/working/error）。
- 按键提示区右侧加 `⌘＋ ⌘－ 字号` 提示。

### 字号缩放（新功能）

- **⌘＋（含 ⌘=）放大、⌘－ 缩小、⌘0 复位**。范围 12–24pt，步进 1pt，
  默认 15pt（现值）。超界时静默钳位。
- 只作用于预览文字；`lineHeight` 随字号等比换算（现 15pt→26pt，即
  `round(fontSize × 26/15)`），文本框高度随之重新标定——**开一场会话内
  面板尺寸不跳**的原则保持：字号调整即时生效即时改高度，这是用户主动
  操作引起的，不算「跳动」。
- 字号存 `UserDefaults`，下次会话沿用。
- **实现约束**：HUD 面板不抢焦点，键盘事件到不了它。这组快捷键走
  ⌥D/esc 同一套会话期全局按键机制，**仅 HUD 可见时拦截**，平时不碰
  其他应用的 ⌘＋/⌘－。esc 的既有语义不变。

## ② 菜单面板

`MenuBarExtra` 从菜单样式切 `.window`，内容自上而下：

1. **头部**：V mark（15pt，琥珀橙）+ `vInput` + 右侧状态（绿点「就绪」/
   琥珀点「听写中」/ 灰点「加载模型…」/ 红点「出错」）。
2. **主按钮**：琥珀橙渐变「开始听写 ⌥D」（听写中变「结束听写」）。
   模型加载中禁用并显示进度语。
3. **设备卡**：**连谁显示谁**。全断开→整块隐藏（内置麦是默认路径，
   不占一行）；连一个→一张全宽卡；两个都连→并排两卡。卡内：设备名 +
   状态点 + 电量（等宽字体）。
4. **上次转写卡**：截断文本 + 「重试 ↻」（琥珀橙文字按钮；不可重试时
   置灰，保留现在「禁用而不隐藏」的理由）。无上次文本时整卡隐藏。
5. **设置四行**：模型 / 校正 / 输出语言 / 翻译后端，右侧显当前值
   （琥珀橙）+ ›。点开**在面板内展开**（disclosure），不弹系统子菜单。
   行内选项、「其他目录…」等动作与现菜单一一对应，**功能零增减**。
   现有文案生成逻辑（`menuLabel`、`outputLanguageMenuTitle` 等在
   model 层由测试钉着的）原样复用，不在视图里拼字符串。
6. **开发期工具**：bench / BLE 扫描保持 `VINPUT_BENCH` / `VINPUT_BLE_SCAN`
   门控，收在设置区之下的折叠段，样式从简。
7. **底栏**：「打开日志」 「退出 ⌘Q」。⌘Q 快捷键保留。

行为：点面板外关闭；面板打开期间数据（电量、状态）照常刷新。
`refreshAvailableModels` 的 onAppear 时机迁移后保持等价。

## ③ 菜单栏图标

替换现在的 SF Symbol（`mic`/`mic.fill`/`waveform`/叹号）。V mark 的
18×18 模板图，状态映射用**无 default 的穷尽 switch**：

| 状态 | 形态 |
|---|---|
| 空闲 | V mark，模板色（自动适应深浅菜单栏） |
| 听写中 | V mark **整体琥珀橙**（非模板）——正在收音必须一眼可辨 |
| 处理中 | 声柱波形化变体（柱高改为中-高-低-高-中），模板色 |
| 出错 | V mark + 右上红点角标 |
| 模型加载中 | 空闲形态 + 半透明角标（优先级最高，沿用现逻辑：加载期菜单一点即关，图标是唯一反馈） |

**本批不做逐帧动画。**

## ④ App 图标

- 深色渐变底（`#2A2A2E→#131315`）圆角方块 + 琥珀橙渐变 V mark。
- **母版就是脚本本身**（`scripts/render-icon.swift`），不额外放 SVG：
  几何已经在 `VMark.bars` 里定死了，再存一份 SVG 等于第三处同源数据，
  而三处必然分叉。脚本渲染 16–1024 全档 PNG → `iconutil` 出 `.icns`，
  接进 `scripts/build-app.sh` 与 Info.plist。生成物（`.icns`）可重建、
  不进版本库；脚本进。
  *（订正于 2026-08-21：定稿时写的是「一份 SVG 母版进 `assets/`」，
  实施时按计划走了脚本单一来源。此处以落地形态为准。）*
- 小尺寸（16/32）已在样机里验证可辨。

## 不做什么

- 设置窗口、onboarding（M9 后续批次）。
- HUD 布局重构、位置/尺寸策略变更。
- 菜单栏图标动画。
- 听写管线、翻译、设备协议——**本批一行不碰**。改动集中在
  `Sources/vInput/UI/` 与 `App/vInputApp.swift`、新面板视图、图标资产。

## 风险

最大风险在菜单面板：`.window` 样式要自己处理点外关闭与键盘可达性，
且现菜单每一项都有行为语义（禁用态、确认弹窗、面板弹出时的 activate）。
迁移判据：**功能与文案零增减，只换壳**。次风险是 ⌘± 全局拦截的误伤面，
靠「仅 HUD 可见时拦截」收窄。

## 测试与验收

- 图标状态映射：穷尽 switch（加状态即编译错误）+ 单测钉每档产物。
- 字号缩放：钳位、步进、复位、持久化、lineHeight 换算进单测。
- 设备卡显隐规则（0/1/2 台的三档）进单测。
- 面板迁移：现菜单里由测试钉着的文案函数全部复用，不新增拼串。
- **每条测试按仓库惯例做变异验证**（判据改坏必须变红，交变异表）。
- 完工后：`./scripts/test.sh` + `./scripts/build-app.sh` 全绿，派**专门
  QA 代理**做跨任务接缝验收（按 `final-qa-agent-before-handoff` 惯例），
  修完 QA 问题再请用户看真机观感（`killall vInput && open dist/vInput.app`）。
- 真机观感验收项：四块资产逐一过；深/浅两种菜单栏下图标可辨；
  ⌘± 在 HUD 可见/不可见两种情形下的行为。
